# 🚗 RentACarProject

**RentACarProject**, C# ve Windows Forms ile geliştirilen katmanlı mimariye sahip bir araç kiralama yönetim sistemidir. Uygulama, araçların kiralanmasını, müşteri yönetimini ve kira işlemlerinin takibini kolaylaştırmayı amaçlar.

---

## 🧱 Proje Mimarisi

Proje 3 ana katmandan oluşmaktadır:

- **RentACar.Desktop** – Windows Forms kullanıcı arayüzü
- **RentACar.BLL** – İş mantığı katmanı (Business Logic Layer)
- **RentACar.DLLModel** – Entity Framework modelleri ve veritabanı işlemleri

---

## 🚀 Özellikler

- 🚘 Araç Ekleme, Güncelleme ve Listeleme
- 👤 Müşteri Ekleme ve Müşteri Listesi
- 📅 Kiralama Başlangıç ve Bitiş Tarihi Seçimi
- 💰 Günlük Fiyat Üzerinden Kira Hesaplama
- 📊 DataGridView ile verileri listeleme
- 🔍 Aktif/Pasif filtreleme (IsActive)
- 🗂 Entity Framework ile veritabanı işlemleri

---

## 🛠️ Kullanılan Teknolojiler

- 💻 **C#**
- 🖼️ **Windows Forms**
- 🗃️ **Entity Framework**
- 🧱 **Katmanlı Mimari (3-tier architecture)**
- 🔧 **MSSQL** (veritabanı için)
